# 📝 Online Examination System

## 📌 Project Description

The Online Examination System is a Java Swing desktop application developed as part of the Oasis Infobyte Java Development Internship.

This application allows users to register, log in, take an online multiple-choice examination, view their score instantly, review correct and incorrect answers, and save the results in a MySQL database.

---

## 🚀 Features

- User Registration
- User Login Authentication
- Multiple Choice Questions (MCQs)
- Automatic Score Calculation
- Correct & Wrong Answer Review
- Store Results in MySQL Database
- View Previous Results
- Logout Functionality

## ▶️ How to Run

1. Import the project into Eclipse IDE.
2. Create the MySQL database.
3. Import the required SQL tables.
4. Add MySQL Connector JAR to the project.
5. Update database username and password in `DBConnection.java`.
6. Run `Main.java`.
7. Register a new user or log in to start the examination.
