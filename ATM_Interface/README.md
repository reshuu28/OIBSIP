# 🏧 ATM Interface

## 📌 Project Description

The ATM Interface is a Java Swing desktop application developed as part of the Oasis Infobyte Java Development Internship.

The application allows users to create an account, securely log in using a PIN, check account balance, deposit money, withdraw money, transfer funds to another user, and view transaction history. All user and transaction data is stored in a MySQL database using JDBC.

## 🚀 How to Run

1. Import the project into Eclipse IDE.
2. Create the MySQL database named **atm_systems**.
3. Create the **users** and **transactions** tables.
4. Update the database username and password in **DBConnection.java**.
5. Run **Main.java**.
6. Register a new user.
7. Login using Username and PIN.
8. Use all ATM features (Deposit, Withdraw, Transfer, Balance & Transaction History).
